Why MLSCA-Bench?

ML-SCA research needs reproducible benchmarks.

Deep learning has become a dominant approach for profiling side-channel attacks, but the ecosystem remains fragmented. Public datasets use different formats, preprocessing choices vary across papers, and models are often evaluated under inconsistent conditions.

MLSCA-Bench aims to provide a common framework for comparing machine learning methods fairly across datasets, devices, countermeasures, and evaluation metrics.

What we are building

A simple, open framework for ML-SCA evaluation.

Unified datasets

Aggregate major public side-channel datasets under a common interface and metadata schema.

Standardized evaluation

Define reproducible preprocessing, train/test splits, metrics, plots, and reporting practices.

Baseline models

Implement classical and modern machine learning models in a shared benchmarking pipeline.
