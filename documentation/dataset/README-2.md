# MLSCA-Bench Dataset Catalogue

This document serves as a guide to the datasets currently included in **MLSCA-Bench**.

The complete dataset catalogue, including download links, metadata, hardware and software implementation details, preprocessing information, references, and additional notes, is available in the accompanying [Excel spreadsheet](dataset_review_with_implementation_and_metadata.xlsx).

## Before You Begin

Please keep the following points in mind when using the dataset catalogue:

- **N/A** indicates that the information is **not available**, either because the dataset itself is unavailable or because the corresponding information could not be found.
- **None** indicates that the dataset is available but does **not provide** the corresponding information.
- Some datasets require creating an account or accepting specific terms of use before they can be downloaded.
- Some datasets are very large (up to **22 GB**). Please ensure that you have sufficient storage space before downloading them.
- Unless otherwise specified, the information reported in the catalogue has been collected from the original dataset repositories, accompanying publications, or by directly inspecting the released files.

The spreadsheet is continuously updated as new public side-channel datasets become available and additional information is verified.
